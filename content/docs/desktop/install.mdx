## System Requirements

<Callout type="info">
  ArcBox Desktop requires **macOS 15 (Sequoia)** or later on **Apple Silicon**. Intel support is in progress.
</Callout>

## Install

<Tabs items={['Homebrew', 'Direct Download']}>
  <Tab>
    ```bash
    brew install --cask arcbox
    ```
  </Tab>
  <Tab>
    Download the latest `.dmg` from [the releases page](https://github.com/arcboxlabs/arcbox-desktop/releases/latest). Open the disk image and drag ArcBox to your Applications folder.
  </Tab>
</Tabs>

The app bundle contains the `arcbox-daemon` runtime, the `abctl` CLI, the guest kernel and rootfs, and the Docker CLI tools. There is nothing else to install.

## First Launch

<Steps>
  <Step>
    ### Authorize the Privileged Helper

    macOS asks for an administrator password so ArcBox can install a small root helper. It manages the `/var/run/docker.sock` symlink, the `/usr/local/bin` CLI symlinks, and the `/etc/resolver/arcbox.local` DNS file — nothing else. See [Helper](./helper).
  </Step>
  <Step>
    ### Boot the System VM

    The daemon seeds the boot assets from the app bundle and boots the Linux guest. The first boot takes a few seconds; later ones are much faster.

    The window shows startup progress while this happens.
  </Step>
  <Step>
    ### Set Up the Command Line

    **Settings → System → Switch Docker & Kubernetes context automatically** is on by default, so `docker` targets ArcBox as soon as the daemon is up.

    To get `abctl` on your `PATH` with completions, run:

    ```bash
    abctl setup install
    ```
  </Step>
</Steps>

## Verify

Open ArcBox Desktop. If the sidebar loads and **Containers** shows a list (even an empty one), the runtime is ready.

From the terminal:

```bash
abctl doctor
```

`doctor` checks the daemon socket, the System VM, the Docker API proxy, the DNS resolver, the network bridge, the container route, and the privileged helper.

## Uninstall

For a complete removal — including the root helper and the system files it manages — run:

```bash
abctl _uninstall
```

It prompts first, then stops and deregisters the daemon LaunchAgent, removes the helper binary, plist, and socket, removes `/etc/resolver/arcbox.local`, `/var/run/docker.sock`, and the `/usr/local/bin` symlinks, drops the `arcbox` Docker context, deletes `~/.arcbox`, and removes `/Applications/ArcBox.app`.

Pass `--keep-data` to preserve `~/.arcbox/data` (images, volumes, machines), or `--yes` to skip the prompt.

<Callout type="warn">
  Without `--keep-data`, this removes every container, image, volume, machine, and sandbox. There is no undo.
</Callout>

<Callout type="info">
  `brew uninstall --cask arcbox` quits the app and unloads the daemon, but it does **not** remove the privileged helper, `/etc/resolver/arcbox.local`, `/var/run/docker.sock`, or the `/usr/local/bin` symlinks — those need root. Run `abctl _uninstall` first if you want a clean system. Adding `--zap` additionally trashes `~/.arcbox` along with the app's preferences and caches.
</Callout>
