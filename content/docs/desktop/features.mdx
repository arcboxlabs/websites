The sidebar groups everything into five sections: **System**, **Docker**, **Kubernetes**, **Linux**, and **Sandbox**.

<Cards>
  <Card title="Containers" href="./containers">
    Docker containers with full Engine API compatibility. Compose project grouping, real-time log streaming, an interactive terminal, and a file browser that reads through the overlay layers.
  </Card>
  <Card title="Images, Volumes, Networks" href="./images">
    Pull and inspect images, create and browse volumes, manage Docker networks — each with its own file browser where it makes sense.
  </Card>
  <Card title="Kubernetes" href="./kubernetes">
    Pods and services from the k3s cluster the daemon manages. Logs and terminal access work the same as with Docker containers.
  </Card>
  <Card title="Linux Machines" href="./machines">
    Full Linux VMs with their own kernel, persistent disk, and a distro you choose. Attach a terminal, browse the guest filesystem, or drive them from `abctl`.
  </Card>
  <Card title="Sandboxes" href="./sandbox">
    Disposable microVMs for AI agents, untrusted code, and CI jobs. Ports, snapshots, file access, and a lifecycle event log.
  </Card>
  <Card title="File Access" href="./file-access">
    Container, image, and volume filesystems mounted at `~/ArcBox` — browsable in Finder, and merged across overlay layers in the app.
  </Card>
  <Card title="Activity" href="./efficiency">
    Live CPU, memory, and network for the System VM and every running container, in one view.
  </Card>
  <Card title="arcbox.local Domains" href="./domains">
    Containers and machines register a DNS name automatically. Reach them at `name.arcbox.local` from your Mac — zero configuration.
  </Card>
  <Card title="Docker-Compatible CLI" href="./cli">
    Bundled `docker`, `buildx`, and `compose`, plus the `abctl` runtime CLI. Existing scripts, CI pipelines, and Compose files work without changes.
  </Card>
</Cards>

## amd64 on Apple Silicon

`linux/amd64` images run next to native arm64 with nothing to configure. On the default Virtualization.framework backend, Intel code is translated by Rosetta; on the Hypervisor.framework backend, by [FEX](https://github.com/FEX-Emu/FEX). Switch backends in [Settings → System](./settings).

## Privacy

<Callout type="warn">
  ArcBox Desktop shares anonymous feature-usage statistics by default. Turn it off in **Settings → General → Privacy → Share anonymous usage data**. No account is required, and no container data, filesystem content, or source code is collected. See [Security](./security) for details.
</Callout>
