<Callout type="info">
  ArcBox Desktop deliberately ships a small set of shortcuts today rather than a speculative map of them. Everything below is what the app actually binds.
</Callout>

## Application

| Shortcut | Action |
|----------|--------|
| `⌘,` | Open Settings |
| `⌘Q` | Quit ArcBox |
| `⌘W` | Close the window |
| `⌘M` | Minimize |

The **New** item is removed from the File menu — creating things happens in the list views, below.

## List Views

In **Containers**, **Images**, **Volumes**, and **Networks**:

| Shortcut | Action |
|----------|--------|
| `⌘N` | Create a new item of that kind (new container, pull image, new volume, new network) |
| `⌘F` | Focus the search field |
| `Esc` | Dismiss search |
| `↑` / `↓` | Move through the list |

Search is also available in **Machines**, **Pods**, and **Services**.

## Sheets and Dialogs

| Shortcut | Action |
|----------|--------|
| `Return` | Confirm — Create, Pull, Run |
| `Esc` | Cancel |

## Terminal

The built-in terminal follows the usual macOS conventions — `⌘C` to copy a selection, `⌘V` to paste. Everything else goes through to the shell, so `Ctrl-C`, `Ctrl-D`, and full-screen programs behave as they would in any terminal.

To use your own terminal app instead, set **Settings → General → External terminal app**.

## Menu Bar

Enable **Settings → General → Show in menu bar** for container controls and live metrics without bringing the window forward.
