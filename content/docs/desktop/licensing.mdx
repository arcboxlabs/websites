## Open Source

Both halves of ArcBox are open source under **MIT OR Apache-2.0**, at your option:

| Component | Repository | License |
|-----------|-----------|---------|
| Runtime, daemon, CLI, helper | [arcboxlabs/arcbox](https://github.com/arcboxlabs/arcbox) | MIT OR Apache-2.0 |
| Desktop app | [arcboxlabs/arcbox-desktop](https://github.com/arcboxlabs/arcbox-desktop) | MIT OR Apache-2.0 |

That covers everything: the VMM, the VirtIO device model, the networking datapath, the filesystem sharing, the container runtime integration, the Docker-compatible API, the Kubernetes integration, the sandbox stack, and the SwiftUI app. There is no closed core and no feature held back behind a paid tier.

## Cost

No account, subscription, or license key is required to use ArcBox. Personal use is free. Commercial use is free during the public beta.

## Brand Assets

The ArcBox name, mark, and screenshots are brand assets and are **not** covered by the source-code license. See [BRAND.md](https://static.arcbox.dev/BRAND.md) before using them — this matters mainly if you fork and redistribute.

## Contributing

Contributions are dual-licensed under the same terms. See [CONTRIBUTING.md](https://github.com/arcboxlabs/arcbox/blob/master/CONTRIBUTING.md) for build instructions and code standards.

## Third-Party Components

ArcBox depends on open-source components including [FEX](https://github.com/FEX-Emu/FEX) for x86 translation, [Firecracker](https://firecracker-microvm.github.io) for sandbox microVMs, [k3s](https://k3s.io) for Kubernetes, and the upstream Docker CLI tools. Their licenses are listed in `NOTICE.md` in the runtime repository.
