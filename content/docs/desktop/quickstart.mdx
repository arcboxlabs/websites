This guide takes you from a fresh install to a running container. It assumes ArcBox Desktop is already [installed](./install).

<Steps>
  <Step>
    ### Pull an Image

    Open ArcBox Desktop and click **Images** under **Docker** in the sidebar.

    Click the pull button, type `nginx`, and confirm. ArcBox downloads the image with layer-by-layer progress.
  </Step>
  <Step>
    ### Run a Container

    <Tabs items={['Desktop', 'CLI']}>
      <Tab>
        Select the image and create a container from it. The new-container sheet lets you set the name, ports, environment variables, volumes, network, and restart policy — the defaults are fine for a first run.
      </Tab>
      <Tab>
        ```bash
        docker run -d -p 8080:80 nginx
        ```
      </Tab>
    </Tabs>

    The container appears in **Containers** immediately. ArcBox follows the Docker event stream, so anything you do from `docker` shows up in the GUI and vice versa.
  </Step>
  <Step>
    ### Read the Logs

    Click the container to open its detail view, then the **Logs** tab. Output streams in real time; search and timestamp toggles are in the toolbar.
  </Step>
  <Step>
    ### Open a Terminal

    Switch to the **Terminal** tab for an interactive shell inside the container — the equivalent of `docker exec -it <container> /bin/sh`.
  </Step>
  <Step>
    ### Browse Its Filesystem

    The **Files** tab shows the container's root filesystem merged across its image layers and its writable layer, so you see what the process sees.
  </Step>
  <Step>
    ### Watch Resource Usage

    Click **Activity** under **System** in the sidebar for live CPU, memory, and network for the System VM and every running container.
  </Step>
  <Step>
    ### Stop and Remove

    <Tabs items={['Desktop', 'CLI']}>
      <Tab>
        Use the stop control on the container row, then remove it once it is stopped.
      </Tab>
      <Tab>
        ```bash
        docker stop <container-id>
        docker rm <container-id>
        ```
      </Tab>
    </Tabs>
  </Step>
</Steps>
